# Compliance

Run `npm run releases -- compliance` with the required arguments from CLAUDE.md. Use --project=CODE for scoped work and --json when checking structured results. Read docs/compliance.md and present record checks as review prompts, never certification.

Use names and codes from the current records. If a reference is ambiguous, show candidates and resolve it. All drafts stay private. Nothing sends or publishes.
