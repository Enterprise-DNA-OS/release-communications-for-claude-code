# Weekly review

Run `npm run releases -- weekly-review` with the required arguments from CLAUDE.md. Use --project=CODE for scoped work and --json when checking structured results. Present the overdue tasks first, then approvals that need a fresh review, then audience evidence and safeguard dates. Name the owner from the records. Do not infer completion.

Use names and codes from the current records. If a reference is ambiguous, show candidates and resolve it. All drafts stay private. Nothing sends or publishes.
