# Record consent

Run `npm run releases -- record-consent` with the required arguments from CLAUDE.md. Use --project=CODE for scoped work and --json when checking structured results. Record only the operator's explicit evidence or review. Ask for missing source or actor information; never invent it.

Use names and codes from the current records. If a reference is ambiguous, show candidates and resolve it. All drafts stay private. Nothing sends or publishes.
